# Arretado 

É um jogo de sobrevivência dinâmico desenvolvido com o framework
Phaser, criado como parte do programa de estágio Lifters 2025.1. O jogo mergulha os
jogadores em um universo com temática do Nordeste brasileiro, combinando elementos
culturais ricos do nordeste com uma temática inspirada na 'Divina Comédia" de Dante Alighieri jogabilidade desafiadora.

**E**ste repositório contém o código-fonte completo do jogo, incluindo a lógica de
jogabilidade, gerenciamento de cenas, sistemas de inimigos e colisões, e todos os assets
necessários. O objetivo é fornecer um exemplo robusto de desenvolvimento de jogos com
Phaser, demonstrando boas práticas de arquitetura de código, modularidade e
gerenciamento de recursos.


# - Funcionalidades

• **Jogabilidade de Sobrevivência:** Enfrente ondas crescentes de inimigos com diferentes
tipos e comportamentos.

• **Variedade de Inimigos**: Lute contra inimigos básicos, de dash, tanques, de longo
alcance e chefes, cada um exigindo estratégias distintas.

• **Sistema de Ondas Dinâmico**: Progressão do jogo baseada em ondas configuráveis,
com duração, música e backgrounds únicos para cada uma.

• **Controles Intuitivos:** Movimentação e tiro responsivos, com um sistema de boost para
manobras rápidas.

• **Sistema de Saúde e Dano:** Gerenciamento de saúde para o jogador e inimigos, com
feedback visual e sonoro.

• **Interface do Usuário (UI) Completa:** HUD com informações essenciais como saúde do
jogador, indicador de onda e cooldown de habilidades.

• **Narrativa Envolvente:** Cutscenes e trilhas sonoras específicas que aprofundam a
história e a imersão no universo do jogo.

• **Modularidade:** Arquitetura de código organizada em componentes e cenas, facilitando
a manutenção e a adição de novas funcionalidades.

• **Gerenciamento de Áudio:** Controle de músicas de fundo e efeitos sonoros para uma
experiência auditiva rica.

• **Customização:** Potencial para seleção de skins e itens que alteram a experiência de
jogo.


# - Tecnologias Utilizadas

• **Phaser 3:** Framework de desenvolvimento de jogos para navegador, utilizado para a
lógica principal do jogo, renderização e física.

• **TypeScript:** Linguagem de programação que adiciona tipagem estática ao JavaScript,
melhorando a manutenibilidade e escalabilidade do código.

• **Webpack:** Empacotador de módulos utilizado para compilar e otimizar o código-fonte
para o navegador.

• **Node.js & npm:** Ambiente de execução JavaScript e gerenciador de pacotes para as
dependências do projeto.

• **Git & GitHub:** Sistema de controle de versão e plataforma de hospedagem de código
para colaboração e gerenciamento do projeto.

• **Phaser3-rex-plugins:** Coleção de plugins para Phaser 3 que estendem suas
funcionalidades, como gerenciamento de entrada e UI.

• **cz-conventional-changelog:** Ferramenta para padronizar mensagens de commit,
facilitando a geração de changelogs e a organização do histórico do projeto.
